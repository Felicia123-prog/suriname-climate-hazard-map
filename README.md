# Suriname Climate Hazard Map
Een interactieve GIS‑applicatie voor het visualiseren van **maandelijkse klimaat‑hazards** in Suriname.  
Deze tool combineert meerdere neerslagbronnen, voert ruimtelijke interpolatie uit en toont de resultaten in een moderne Streamlit‑webapplicatie voor de **Klimaat Impact‑pagina**.
